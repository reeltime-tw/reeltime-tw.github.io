# 改版方針 v3：改名 Reeltime、追蹤場次通知、UI/UX 全面修正

> 規劃：Opus（2026-11-24）。執行：Sonnet。對使用者的說明一律繁體中文、白話。
> 先讀 `CLAUDE.md`（尤其「定位與隱私」「路程時間」相關段落），再讀這份。
> 網站是單一檔案 `docs/index.html`（約 1000 行）。這次只改網站，**不要動爬蟲與排程**（`scrape/`、`windows/`、`data/`）。

## 0. 不能破壞的東西（每項改完都要確認）

1. **隱私承諾**：`<meta http-equiv="Content-Security-Policy">` 保持 `connect-src 'self'`，不得加任何外部網域；不得引入外部字型、腳本、分析工具。新增的 Service Worker 也只能抓自己網站的檔案。
2. 位置相關：只有使用者按按鈕才要定位、經緯度只放記憶體（`S.here`）、不寫進儲存。隱私說明面板（`privacySheet`）的每一句都必須仍然屬實；新功能要在裡面補一段說明。
3. 既有功能都要保留且可用：縣市選擇與自動定位、搜尋（上方全螢幕、不被鍵盤擋）、篩選（時段自填「從／到」、特殊廳、語言、品牌）、常用影城（星號）、影城卡片收合、出發時間／路程查表（`travelLookup`、`leaveHTML`、地圖連結）、訂票連結、hash 路由、手機返回鍵先關面板（`ignorePop`）、捲動位置記憶、午夜場排序（`tkey`）、已開演場次隱藏、海報備援、示範資料。
4. iPhone 細節（程式註解裡有寫原因，不要移除）：面板開啟時不自動聚焦時間欄位、搜尋框用 `autofocus` 而且在頂部、`font-size:16px` 的輸入框避免縮放。
5. 資料格式 `docs/data.json` 不變。

## 1. 改名：開場 → **Reeltime**

- 理由：Reel（電影膠卷）＋ real-time（即時場次），好念、跟「場次即時更新、有新場次就通知」的定位一致。中文副標維持「全台電影場次」。
- 要改的地方：`<title>`、`application-name`、`apple-mobile-web-app-title`、`manifest.webmanifest` 的 `name`（`Reeltime｜全台電影場次`）與 `short_name`（`Reeltime`）、頂部品牌字、`boot()` 載入中的品牌、所有 `document.title`（`｜開場` → `｜Reeltime`）、`CLAUDE.md` 裡的名稱。用 `grep -n 開場` 確認全部改完（「開場」若是指電影開演的一般用語則保留，例如「開場前」）。
- 品牌字樣式：英文字用 `Barlow Condensed` 700、字距 .3px，不要沿用中文的 2px 字距。圖示不換。

## 2. 新功能：追蹤場次，有新場次就通知

使用者需求：選電影（必填）、日期（選填）、時段（選填），**只要有符合條件的新場次就通知**。

### 限制（要誠實寫在畫面上）
網站沒有伺服器，而且 CSP 只允許連自己的網站，所以不做推播伺服器。通知方式：
- **打開 App 時**：自動比對，有新場次就在「追蹤」分頁顯示紅點數字、頁面上方出現提示，並（有授權時）跳系統通知。
- **App 沒開時**：用 Service Worker 的 Periodic Background Sync 在背景檢查。只有 Android Chrome「安裝成 App」後才支援；iPhone 不支援背景檢查，要打開 App 才會檢查。畫面上要用一句話說清楚。

### 資料
- 儲存：`localStorage` 的 `twc.watches`（陣列），同時鏡像一份到 IndexedDB（Service Worker 讀不到 localStorage）。
- 一筆追蹤：`{ id, movie: 電影 id, title: 片名, area: '台北市'|'全台'|'fav'(常用影城), dates: []（空＝不限，否則 YYYY-MM-DD 陣列）, from: 'HH:mm'|'', to: 'HH:mm'|'', seen: [場次鍵], newKeys: [場次鍵], created, checkedAt }`
  - 電影 id 是片名正規化後的雜湊（見 `scrape/index.mjs`），各次更新穩定，可直接用。
- 場次鍵：`cinema|date|time|format`。
- 符合條件：電影相同、日期在 `dates` 內（空則今天以後都算）、時間在 from/to 內（沿用 `tkey` 的午夜場規則）、影城在 area 內（`fav`＝目前常用影城）、未開演。
- 建立時：把目前已符合的場次全放進 `seen`，並告訴使用者「目前已有 N 場符合」（可直接點去看）。之後每次載入資料，符合但不在 `seen` 的就是**新場次**，加入 `newKeys`；使用者看過該追蹤後把 `newKeys` 併入 `seen` 並清空。
- 已經過去的日期自動從比對中排除；若 `dates` 全部過期，該追蹤標示「已結束」。

### 介面
- 底部分頁加第 4 個「追蹤」（鈴鐺圖示），有新場次時顯示紅色數字。路由 `#/watch`。
- 電影頁標題區加「追蹤新場次」按鈕（鈴鐺）。已追蹤時顯示「追蹤中」，點擊可編輯。即將上映（還沒開賣）的電影特別有用：文案「開賣時通知我」。
- 空狀態（這天場次還沒公布／沒有符合場次）加按鈕「有場次時通知我」→ 直接帶入目前的電影、日期、時段建立追蹤。
- 建立／編輯面板（底部面板）：
  - 電影（顯示海報與片名，不可改）
  - 地區：目前縣市（預設）／全台／只看常用影城（沒有常用影城時隱藏）
  - 日期（選填）：「不限」＋未來 14 天的日期按鈕可複選
  - 時段（選填）：沿用篩選的「從／到」時間欄位與說明
  - 即時預覽：「目前有 N 場符合」
  - 按鈕：「開始追蹤」／編輯時「儲存」「取消追蹤」
  - 第一次建立後才詢問通知權限（先用一句話說明用途，再呼叫 `Notification.requestPermission()`）；拒絕也能用 App 內提示。
- 追蹤頁 `#/watch`：每筆一張卡片（海報、片名、條件摘要如「台北市・11/28、11/29・18:00 後」、新場次數或「目前 N 場符合」），點卡片展開新場次清單（沿用票根 `stubsHTML`，點了一樣開訂票面板），右上可編輯／刪除。頁首一行說明通知方式與目前權限狀態（已開啟／未開啟→按鈕開啟／被封鎖→說明到設定開啟）。沒有追蹤時顯示空狀態與說明。
- 通知內容：標題「Reeltime：《片名》有 N 個新場次」，內文列前 3 場「11/28（五）19:30 台北信義威秀」，點通知開啟 `#/watch`。

### Service Worker（新檔 `docs/sw.js`）
- 註冊範圍為網站根目錄；**不要做離線快取**（避免看到舊場次），只負責背景檢查與通知點擊。
- `periodicsync`（tag `twc-watch`，`minInterval` 6 小時，只在支援時註冊）：抓 `data.json`（no-cache）→ 從 IndexedDB 讀追蹤 → 用與頁面**同一套比對規則**算新場次 → 寫回 IndexedDB → `showNotification`。比對函式請寫成頁面與 SW 共用的一段純函式（可放在 `docs/watch-core.js`，頁面用 `<script src>`、SW 用 `importScripts`），避免兩邊規則不一致。
- `notificationclick`：聚焦已開的視窗或開啟 `./#/watch`。
- CSP 可能需要補 `worker-src 'self'`（仍只限自己網站）。

## 3. UI／UX 修正（依優先順序）

### P1（一定要做）
1. **訂票面板**：主要動作優先。面板頂部是電影／影城／時間摘要；「到 XX 訂票」主按鈕固定在面板底部（sticky），不需捲動就看得到；「出發時間」預設收合成一列（已有位置時顯示「最晚 HH:MM 出門 ›」，沒有位置時顯示「規劃出發時間 ›」），點開才顯示交通方式、提早到、地圖按鈕與說明。預設狀態的面板高度不超過一個手機畫面（375×812）。
2. **電影頁**：日期列與版本／語言快捷鈕在捲動時固定在頂部（放進 `#sub`，跟首頁一樣在 header 裡），不用捲回頂端換日期。標題區精簡：海報寬 88px、簡介預設 2 行。加入「追蹤新場次」按鈕。
3. **首頁電影格**：手機寬度 ≥ 360px 時改 3 欄（現在 2 欄一個畫面只看得到 2 部，總共近百部）。卡片文字：片名最多 2 行 14px；下方一行「下一場 10:30・12 間」（間＝目前地區有場次的影城數，比總場次數有意義；「最快」改稱「下一場」）。
4. **首頁定位提示卡**：改成高度不超過 72px 的單行橫幅：「只看附近影城？［使用目前位置］［選縣市］×」，可關閉（記住不再顯示）。隱私說明連結移到縣市面板（已有）。
5. **對比**：`--ink3`（#8a909c）在白底只有約 3.3:1，小字看不清。改成至少 4.5:1（例如 #6b7280），檢查所有 12–13px 的灰字。
6. **過時文案**：頁尾「每天早上更新一次」改成「每天多次自動更新」；資料來源面板「每天早上 8 點」同步修正（實際排程：08:00、14:00、18:00、20:00、21:00 完整更新，另有各影城公布時段的加抓）。
7. **影城列表**：每列只留一行副標「品牌・縣市」；公布資訊只顯示「下次公布 11/25（三）」一短句（官方公告才加「官方」標籤），不要兩行換行。右側數字標籤改「今天還有」；今天沒有場次時顯示「今天無場次」小字取代「–」。

### P2（時間允許就做）
8. 頂部更新時間改相對時間：「2 小時前更新」（超過 24 小時顯示日期並用警示色）。
9. 即將上映頁也用 3 欄；「已開放預售」標籤樣式與首頁「預售」一致。
10. 視覺一致性：建立並套用 type scale（頁標 22/28、區塊標 17/24、內文 15/23、輔助 13/19、極小 12/17）、間距 4/8/12/16/24、圓角層級（大卡 16、一般 12、票根 8、膠囊鈕 999）。卡片用極淡陰影 `0 1px 2px rgba(22,24,29,.06)` 配 1px 邊框，讓層次清楚但不花俏。
